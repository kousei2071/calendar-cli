# じかんぷらす

コンソール上で予定を管理する Java アプリです。予定の登録・一覧・直近の確認・編集・削除ができます。

データはメモリにだけ持つので、アプリを終了すると消えます。ファイル保存はありません。

## 動かし方

JDK が入っていれば動きます。Eclipse で開いている場合は `presentation.Main` を実行してください。

ターミナルから動かす場合:

```bash
mkdir -p bin
javac -d bin -sourcepath src src/presentation/Main.java
java -cp bin presentation.Main
```

起動するとメニューが出ます。

```
[1] 予定の登録
[2] 予定の一覧表示
[3] 直近の予定を表示
[4] 予定の編集
[5] 予定の削除
[0] 終了
```

登録時の日時は、次のどちらかで入力します。月・日・時・分のゼロ埋めは不要です。

```
2026-10-17 14:30
202610171430
```

「直近の予定」は、今よりあとの予定を日時の早い順に、指定した件数だけ出します。編集・削除は一覧に出る ID を指定します。

## ソースの置き場所

処理の役割ごとにパッケージを分けています。

```
src/
  presentation/   メニューと入力
  usecase/        登録・一覧・検索・編集・削除
  domain/         予定と準備物
  repository/     メモリ上の保存と ID 発行
```

準備物用のクラスはありますが、今の画面では使っていません。登録時の「持ち物」は予定の説明文として保存しています。
